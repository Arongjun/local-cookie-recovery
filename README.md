# Local Cookie Recovery

一个在本机导出和合并 Chromium 浏览器 Cookie 的 Manifest V3 扩展。适合将自己的 Cookie 从 ego 等 Chromium 浏览器迁回 Chrome。

扩展不向服务器发送 Cookie，不依赖第三方库，也不需要关闭浏览器的加密保护。数据通过浏览器提供的 `chrome.cookies` API 读取和写入。

## 功能

- 导出当前浏览器可读取的普通 Cookie 和分区 Cookie。
- 合并时保留目标浏览器已有记录，同一域名、路径、名称和分区键的记录不覆盖。
- 跳过过期记录，记录失败原因，完成后回读核对写入结果及原有记录变化。
- 将“回读一致”“浏览器调整属性”和“写入失败”分别统计，避免仅凭 `set()` 返回值误判。

## 安装与迁移

1. 下载本仓库并解压，保留在一个固定目录。
2. 在源浏览器打开 `chrome://extensions/`，开启开发者模式，选择“加载未打包的扩展程序”，选中包含 `manifest.json` 的目录。ego 可通过其扩展管理页执行同样操作。
3. 在扩展菜单打开 **Local Cookie Recovery**，点击“导出全部 Cookie”，保存 JSON 文件。
4. 在目标 Chrome 中加载同一扩展，打开弹窗，选择刚才导出的 JSON 文件，点击“合并缺失的 Cookie”。
5. 等待处理后点击“查看结果”。弹窗关闭后，后台仍会继续处理；重新打开可查看保存的报告。
6. 验证常用网站登录情况。完成迁移后删除 Cookie 导出文件；不再需要时可停用或移除扩展。

移动扩展目录后，需要从新目录重新加载扩展；删除目录会使未打包的扩展无法使用。

## 数据与权限

导出的 JSON **包含明文 Cookie，可能包含登录凭证**，请勿上传至 GitHub、公开网盘或发送给他人。仓库的 `.gitignore` 会忽略除 `manifest.json` 以外的 JSON 文件，但上传前仍应自行检查。

扩展声明的权限用途：

| 权限 | 用途 |
| --- | --- |
| `cookies` | 通过浏览器 API 读取和写入 Cookie |
| HTTP/HTTPS 主机权限 | 访问各网站的 Cookie |
| `downloads` | 将用户主动导出的数据保存为本地文件 |
| `storage` | 保存统计及错误报告，不保存导入的 Cookie 正文 |

扩展没有网页内容脚本、外部消息接口或自动迁移任务。导入和导出均由弹窗按钮触发。

## 限制

- 本工具只处理 Cookie，不迁移书签、历史记录、密码、Local Storage、IndexedDB 或其他扩展的数据。
- Cookie 写入成功不保证登录一定有效。网站可能要求设备验证、其他本地存储数据或重新登录。
- Chrome 可以拒绝不符合其规则的 Cookie，或调整属性和有效期；本工具不会通过改变分区边界等方式绕过拒绝。
- 会话 Cookie 仍受目标浏览器的退出和会话恢复设置影响，不会自动变为永久 Cookie。
- 合并不是事务，取消或中断后可能已有部分记录写入。再次合并会跳过已存在记录。
- 最多接受 20,000 条导入记录。重复判定不包含跨配置文件的 `storeId`；工具处理当前扩展所在的默认 Cookie 存储。
- “原有记录变化”也可能来自同时打开的网站，不应仅据此认定是迁移导致。

## 开发与自检

无需构建和安装依赖。使用支持 ES 模块的 Node.js 执行：

```sh
node check.mjs
```

自检覆盖分区 Cookie、保留冲突、重复输入、过期记录、拒绝写入、属性变化、误导性写入返回值和回读缺失。它使用内存模拟 API，不读取真实浏览器数据。

修改源码后，在浏览器扩展管理页点击“重新加载”生效。自检通过不代表所有 Chromium 版本和网站均已兼容。
